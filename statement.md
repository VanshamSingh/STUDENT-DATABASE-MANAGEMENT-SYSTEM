# Project Statement

## Student Management System

The aim of this project is to develop a simple **Student Management System using Python** that can be used to store and manage basic student information.

In a manual system, maintaining student records, updating details, entering marks and checking grades can become time-consuming. This project provides a simple menu-based solution where the user can create, view, update and delete student records.

The system also allows marks to be entered for students and automatically calculates their grades. An academic report can be generated to display the marks and grades of the available students.

The project is divided into different Python modules to keep the code organized. Student information is stored using Python dictionaries, while file handling is used to save the data in `student_db.txt` so that the records can be loaded again when the program is restarted.

### Main Objectives

- To manage student records using Python.
- To perform basic CRUD operations.
- To store student marks and calculate grades.
- To generate a simple academic report.
- To practice Python functions, dictionaries, modules and file handling.
- To understand how a small real-world application can be divided into different modules.

### Technologies Used

- **Programming Language:** Python
- **Data Structure:** Dictionary
- **Storage:** Text file (`student_db.txt`)
- **Interface:** Command-line / Terminal

### Conclusion

This project provides a basic and easy-to-understand way of managing student information. It is mainly developed as a learning project to apply Python programming concepts to a practical problem. It can be further improved by adding a database, graphical interface, login system and more academic features.
